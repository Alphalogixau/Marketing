## The one-page version

**Positioning:** Honesty builds trust. In a category where everyone claims the same
things, telling people what they *don't* need is the only differentiator competitors
can't copy without actually doing it.

**Organising line:** See More *(surveillance)* · Respond Faster *(managed IT)* ·
Stay Secure *(cyber)* — already in use, and stronger than it's being asked to be.

**Two offers, both honest:**
- Free 15-minute security review — "we'll tell you what's exposed, even if you never hire us"
- Free site walkthrough — "your existing cameras might already do this"

**Paid:** 100% Meta at $500–1,500/mo. LinkedIn organic only until spend clears ~$4k/mo.
