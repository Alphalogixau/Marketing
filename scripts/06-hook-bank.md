# Hook Bank — First 3 Seconds

The hook decides whether the ad works. Everything after it only matters if the hook
lands. Test hooks against the *same* body footage — that isolates the variable.

**Method:** 3 hooks per script, same body, run simultaneously, ~$10/day each for 5–7
days. Kill anything below 25% 3-second-view rate. Winner becomes the control; next
test challenges it.

## Cyber / Stay Secure

| # | Hook | Angle |
|---|---|---|
| A | "I'm going to tell you something most IT companies won't." | Confession *(control — Script 01)* |
| B | "Almost every breach we get called into isn't sophisticated." | Contrarian |
| C | "A client got hacked from one email. Then we found something worse." | Story *(proven — this was the best-performing organic post)* |
| D | "If your IT provider told you antivirus is enough, get a second opinion." | Direct challenge |

## Surveillance / See More

| # | Hook | Angle |

## Notes

- **Cyber C** and **Surveillance B** are lifted from posts that already performed
  organically. Start there — they're the only two with any evidence behind them.
- **Surveillance C** will feel wrong to run. Run it anyway. Anti-sell hooks
  massively over-perform for high-trust categories and it is exactly on-brand.
- Never test hook *and* body at once. You won't know which moved the number.
