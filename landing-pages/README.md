# Landing Pages

One page per Google campaign. **Never send paid traffic to the homepage** — it is the
most expensive mistake available at this budget.

| Page | Campaign | Offer |
|---|---|---|
| [`01-change-it-provider.md`](01-change-it-provider.md) | Displacement · $500/mo | Free 15-min review |
| [`02-security-cameras.md`](02-security-cameras.md) | Surveillance · $700/mo | Free site walkthrough |
| [`03-managed-it-sydney.md`](03-managed-it-sydney.md) | Managed IT · $600/mo | Free 15-min review |

## Rules for all three

1. **No navigation menu.** Every nav link is an exit.
2. **Message match.** The H1 must contain the search term. Google scores this directly
   — better match means higher Quality Score means lower CPC for the same position.
3. **One offer per page.** Two CTAs halve both.
4. **Under 2.5s load.** Slow pages are penalised with higher CPCs.
5. **Mobile first.** Over half this traffic is on a phone.
6. **Fire the `Lead` pixel event on the thank-you page**, not on button click.
7. **Click-to-call phone number top right** on every page.
